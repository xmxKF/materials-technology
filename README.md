# Materials & Technology

Multilingual corporate website concept for semiconductor materials, inspection equipment and solar-related business.

Traditional Chinese, Simplified Chinese, Japanese and English share reserved layout geometry. Language selection is remembered locally. GitHub Pages uses browser time-zone and language hints; it does not provide exact IP geolocation.

Images are AI-generated conceptual illustrations, not photographs of company facilities or representations of supplied product models. The ceramic ring and optical inspection unit are reference images; interactive 3D is deferred pending multi-view references.

This repository contains the public static website only. GitHub Pages publishes the `main` branch root. Relative asset URLs support the repository subpath. The company identity and contact information remain placeholders until confirmed.

The page includes repeatable scroll reveals in both directions and respects reduced-motion preferences. No sign-in is required to view this website. No analytics, external font service, or third-party geolocation request is used.
